# Design reference

Authority: upstream UI/theme and latest AGENTS corrections at the locked Android SHA. No desktop sidebar or new visual identity is approved.

Dark tokens: yellow #FFBD00, black #000000, card #18181B, raised/border #262626, text #ECECEC, muted #A1A1AA. Light and device themes are retained. Satoshi is the UI face; ASCII uses monospace. Interface hierarchy follows 26/34 headings, 20/28 secondary, 16/24 body and 14/20 supporting text. Memory cards retain their 24dp metadata strip, 18dp outer envelope, 4dp inset and 14dp inner surface, with 15dp note titles.

Home, Alter AI, Memories, Upcoming and Notes stay in original order along the bottom, using upstream rounded vector glyphs and Alter mark. No glass/gradients across the app. Chat alone has a neutral translucent matte prompt and quiet rim with 12dp corners. Settings uses categories/subpages. Capture remains bottom-anchored; full Android anchor expansion/return motion and directional page transitions are still pending, not replaced by a different claimed animation.

One root-owned river simulation/renderer is preserved across destinations and dialogs. Home/Memories/Upcoming/Notes show it only when the destination has no content, independent of search results; chat always shows it, dimmed with saved messages. Source species/geometry/cruise and fixed square ASCII grid are retained. Rendering pauses when hidden, inactive or motion is reduced; the first static frame remains available with reduced motion. Desktop visual acceptance, DPI/resize and original capture/nav motion are pending.
