# Alter desktop design review

Open [the HTML prototype](desktop-review.html) in a browser and use its left navigation. It is a visual proposal using sample content, not the running Windows app. The first installed app currently opens to an empty workspace; this proposal needs an accepted empty-state layout before porting.

Full-size screen images:

[All screens at a glance](previews/overview.png). The HTML is local and self-contained apart from the existing Alter logo and locally installed Satoshi font assets; it falls back to the system sans serif when fonts are absent. Buttons switch prototype screens, while sample actions do not save user data.
